# Modules

Core (`src/lib`, `src/components`, and app paths outside module manifests) never imports a module. `src/config/modules.ts` and `src/config/module-lifecycle.ts` are the registry exceptions. Project code in `src/features/` may import any installed module. A module may import another module only when its manifest lists that module in `dependsOn`. Add a folder under `src/modules/<id>` with `module.ts`, `module.json`, and any server, component, schema, or env files it needs. Add its Prisma model in `prisma/schema/<id>.prisma` when needed. Put the import and array entry in `src/config/modules.ts`, each ending with `// module:<id>`. User deletion hooks in `src/config/module-lifecycle.ts` use the same marker.

The manifest fields are `id`, `name`, `description`, `paths`, `prismaFiles`, `packages`, `envKeys`, and `dependsOn`. `paths` contains `src/modules/<id>`, module-named route branches under `src/app/api/`, `src/app/(dashboard)/dashboard/`, `src/app/(dashboard)/admin/`, or `src/app/(marketing)/`, and `tests/e2e/<id>.spec.ts`. The installed admin, billing, contact, and uploads modules also have exact legacy route paths. `prismaFiles` contains only `prisma/schema/<id>.prisma`. `packages` contains lowercase npm package names, without versions or command syntax. List dependencies on other modules in `dependsOn`.

Run `npm run module:list` to inspect installed modules. Preview removal with `npm run module:remove -- <id> --dry-run`, then run without `--dry-run`. The preview lists every file scheduled for deletion and imports of the module in `src/`, `tests/`, `scripts/`, and `prisma/` outside its manifest paths, with file and line numbers. Removal stops before changes when these imports exist. Pass `--force` to proceed despite those references; the script still prints them. The script blocks removal when another installed module depends on it, rejects symlinks in deletion paths, removes owned paths and both registry markers, removes env keys from `.env.example`, and uninstalls packages only when no remaining source imports them or remaining module manifest declares them. Run `npx prisma migrate dev` afterward to drop removed tables.

To swap email transport, set `EMAIL_PROVIDER` to `resend` or `smtp` and supply the matching env keys. To remove Resend entirely, delete `src/lib/email/providers/resend.ts`, remove its import and map entry in `providers/index.ts`, then uninstall `resend`.

Every module must be tested: `npm run check:module-tests` fails when a module logic file has no unit test that imports it or the module has no `tests/e2e/<id>.spec.ts`. The cases the tests cover are listed in `CLAUDE.md` section 3.
