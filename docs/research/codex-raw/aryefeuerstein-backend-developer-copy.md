## Project

**EZ Returns backend:** API for a package pickup and returns service. Single-package JavaScript project using Express `^4.18.2`, MongoDB/Mongoose `^7.0.0`, JWT/bcrypt auth, and no frontend styling or client state. The documented Next.js frontend is absent, so its version cannot be determined.
